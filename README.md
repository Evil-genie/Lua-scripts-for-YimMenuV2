# Lua-scripts-for-YimMenuV2
Mostly updates lau script for YimMenuV2. I'm not the creator, just compiled all lua scipts I found online in here, so use at your own risk.

To install any script here are the steps:
1. Download the lua script to a folder
2. Press windows + r, type %appdata% and hit enter
3. Navigate to YimMenuV2 > scripts
4. Cut/copy paste the downloaded lua file in the scripts folder
